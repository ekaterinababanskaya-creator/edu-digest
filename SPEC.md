# EduDigest — техническое задание

## Зачем
Еженедельная сводка важных новостей рынка K-12 (Россия и мир) для Кати и команды Домашней школы Фоксфорда. Цель: за 10 минут понять, что изменилось в регулировании, на рынке и в практике школ, и что из этого важно для нас.

## Пользователи
Катя и команда: продукт, методология, аналитика. Читают в браузере, с компьютера и с телефона.

## Что делает приложение (MVP)
1. **Собирает** материалы из источников, перечисленных в файле `sources.yaml`. Для каждого источника достаточно указать адрес сайта: RSS-ленту приложение находит само.
2. **Фильтрует**: оставляет материалы за последние 7 дней, убирает дубли и то, что не касается K-12.
3. **Пишет сводку** на русском языке с помощью Claude (зарубежные материалы переводятся и пересказываются).
4. **Публикует** сводку как веб-страницу. Старые выпуски сохраняются в архиве.
5. **Расписание**: автоматически каждый понедельник в 9:00 по Москве. **По запросу**: запуск одной кнопкой.

## Формат сводки
- **Главное за неделю**: 3–5 самых значимых событий.
- **Россия: регулирование и госполитика** (Минпросвещения, Рособрнадзор, ФГОС, ГИА, семейное обучение).
- **Россия: рынок и EdTech**.
- **Мир: K-12 политика и практика**.
- **Мир: EdTech и инвестиции**.
- **Исследования и данные**.

Каждая новость оформляется так: заголовок, 2–3 предложения сути, строка «Почему это важно для Домашней школы», ссылка на источник. Если в разделе за неделю ничего нет, раздел пропускается.

## Фильтры на странице
Каждой новости присваиваются теги, по которым сводку можно отфильтровать:
- ФГОС
- Экзамены (ГИА: ОГЭ, ЕГЭ)
- Семейное образование
- Законодательство (федеральное)
- Законодательство по регионам РФ (для этого понадобятся региональные источники, добавим отдельным этапом)

## Как устроено
- `sources.yaml`: список источников. Добавить источник значит дописать одну строку.
- `collect.py`: сбор и фильтрация материалов.
- `summarize.py`: составление сводки через Claude API.
- `build.py`: сборка HTML-страницы и архива.
- GitHub Actions: запуск по расписанию и по кнопке «Run workflow».
- GitHub Pages: хостинг страницы.

## Не входит в MVP (позже)
- Telegram-каналы как источники.
- Форма добавления источников прямо на странице.
- Поиск по архиву, теги, отправка в Telegram или на почту.

## Готово, когда
- Страница открывается по ссылке и показывает свежую сводку.
- Сводка обновляется сама по понедельникам и по кнопке.
- Новый источник подключается правкой одной строки в `sources.yaml`.

## Этапы
1. Скрипт печатает список свежих материалов из всех источников и отчёт о том, какие источники работают.
2. Фильтр: 7 дней, дубли, релевантность.
3. Сводка через Claude.
4. Веб-страница и архив.
5. Расписание и кнопка запуска.
